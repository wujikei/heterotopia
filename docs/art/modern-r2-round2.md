## 实际交付与边界

- 两个统一立绘底图：林越、原稿无名室友。每人六态，合计12张864×1152透明运行母版；导出桌面/移动WebP、AVIF。
- 林越：平静、思考、微笑、困惑、警觉、惊愕。保留二十岁、圆框眼镜、灰蓝开衫、白T、绿包的既有身份。
- 室友：平静、专注、微笑、困惑、关切、惊愕。原文只给关系与行为，未给姓名/具体外貌。外观延续旧分面CG右侧卷发、暖肤色、米色针织衫的角色；耳机有原稿依据。这是项目视觉设定，不补民族/国籍/新剧情。
- 实际生成14次调用：1次被打断未返回文件，13次返回，12份选用，1份室友候选因过像林越弃用。弃用候选不进运行资源。每人五份情绪源是独立参考生成，不是滤镜变色。
- 采用同一透明身体、固定脸骨/发际线/外轮廓、配准眉眼与颊唇的不规则羽化表情层。不是矩形脸片，也不是六套重新设计的身体。
- `scripts/check-modern-characters-r2.py` 严格检查：每人所有态alpha/身体锚点一致；10个表情层与两个透明底可逐像素重建12份PNG母版。该精确断言针对PNG母版，AVIF另做解码检查。

## 第一轮UI反馈与窄窗黑帧：仍是待复核项

正常无痕UI已通过拿玉图文同步、宿舍16/28宽窄构图、灯灭正文、自然读到27/28发光，以及一段减弱动态。无真机手机、未实际听声音。

父代理截图确实显示：16/28手刻有图，17/28“以为是公开课的片段，伸手滑进度条”同一CG却黑。不能据此编造根因。旧40b3450的144次几何/DOM观察（含独立4191的415/623冷启动和DPR1.5直接导入05）未捕获零高/透明状态；这不是144次人工通读或逐帧像素排除。

本轮做了两项局部修正：读文安全区测量随真实页、已加载URL和字体就绪更新，未布局节点不当作零高度；窄屏可变高度画区与opacity动画解耦，保持静态绘制，宽屏保留短淡入。新增测试检查的是截图真实非黑像素，不只是URL/高度。最终版本通过73个非黑截图观察、5组视窗条件（含DPR1.5）、逐页回看和两角色演出。完整单元122项通过，类型与构建通过。

**这不等于已经证明原黑帧的唯一根因。发布阻断尚未关闭，需同一路径正常UI复核。若仍出现黑帧，保留现场，记录画面URL/高度/opacity/遮罩再定位；不要把浏览器问题当成已证事实，不要以全局overflow隐藏等手段遮掩。**

## 普通UI验收：只点一次续梦

生成合成定位档：

```sh
node --import tsx scripts/make-modern-r2-acceptance.mjs artifacts/modern-art-r2/acceptance-saves
```

无痕/隔离环境 → 林越·现代新卷 → 阅读设置 → 导入JSON → 等成功提示 → 关闭设置 → **只点一次续梦**。续梦不出章节卡，不再点画面“进入故事”；多点一次会推进一页。先按`manifest.json`的正文和页码核对落点。

- `02`：17/36掌心拿玉。连续读三页再回看，点刚读过的句子重读，不能以空历史证明回看正常。
- `05`：16/28手刻。固定窄窗连续点至17、18、19、20，再到27；中途宽窄切换一次。每页保留画面。
- `06`：20/28灯灭；`07`：27/28玉扣亮。若看到21或28，是已比种子多前进一页，不是这两个种子的目标。
- `08`：9/28第一声何，连读至两次思考、困惑，再进入CG。人物不要盖CG。
- `09`：返场“夜里，室友”前一拍，下一页想家了，再看林越两种反应，随后分面CG。
- `10`：办公室“想”与“我想弄懂它”。

历史由引擎逐页推进产生，不伪造句子；开场两场连续推导，晚段从合成场景入口开始。它仍不是人已读完全文，也不表示古代两线已通关。不要导入普通存档或按普通重新启程。
