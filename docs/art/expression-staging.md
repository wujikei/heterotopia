## 验证口径

- 编译空周目、已有双线记忆周目与含旧名记忆的周目，并分别覆盖早餐 A/B 分支；26 个 ID 都必须真实存在。
- 对每一条用 `actorForBeat` 解析实际演员，检查请求的表情在该演员 `AVAILABLE` 中，禁止把回落到默认图当作差分生效。
- 用 `cgForBeat` 排除被 CG 遮住的页面；本表 26 处均在可显示立绘的对白页。
- 按独立分页去重后的注释覆盖：沈辞 5、戌 4、唐瑾 2、阿媪 3、屈衡 3、雩 3、媭 3、沅 3。该数字只统计本表注释，不等于全剧由情绪标记识别到的全部表情页。
- 本批不强行调度闭眼等缺少充分当前对白依据的状态，也不声称所有已交付状态都已在剧本中用过。
