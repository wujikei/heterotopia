# 第三批界面与叙事美术验收

基线：`5dcf2b2`；开发分支：`ui-fix-3`。剧本文字、分支规则和立绘人物名字保留。本批通过 PR 审查，确认合并后由现有 GitHub Pages 工作流上线。

## 阅读与画质

- 设置新增“轻量模式”：开启延用较小的 AVIF/WebP 背景；关闭使用原始分辨率、逐像素无损 WebP。默认关闭，设置随浏览器保存。27 张原画实际选择后才下载，缺失时回退轻量背景。CG 与人物立绘不随此设置变化。
- 手机人物志调整人物、姓名、身份与正文的关系；支持已阅读配角的解锁。标题页在 Save-Data 下打开人物志也会按需取得剧情元数据，旧存档不必先续梦才能解锁。
- 书签优化六格排版、空位对比和确认状态；回看中旁白靠近正文左缘，减少空列，保留安全重读边界。
- 自动阅读从打字结束开始计时，短句保留停顿，长句多留阅读时间；设置新增“选择后继续自动阅读”。弹窗、章节卡、隐藏界面和后台页面继续暂停推进。
- 结局印章使用明确的字符列，修正旋转后的几何验收；引语末尾保持连排。绘卷支持山河/CG 分类、隐藏说明的沉浸看图、方向键、左右滑动及逐层 Escape 返回。
- 盖章声从实际动画开始时计时，在约 300ms 接触点播放；预解码减少网络带来的声音滞后。菜单打开、关闭、保存与切换使用不同的现有声音映射，并遵守静音和音效音量。

## 美术交付

- 28 张新增差分加 8 张既有平静立绘，共 36 个重点角色状态；沈辞、戌各 6 种，屈衡、媭、雩、阿媪、唐瑾、沅各 4 种。雩保留蒙眼布，媭保留右臂空袖。
- 26 处明确的表情演出标注覆盖以上八位角色，逐一核验对应台词、实际发言者、差分资源及 CG 遮挡条件；并保留对原有情绪标记的保守识别。资源导出数不等同于每种差分都有独立剧情触发。依据与适度演绎的区别见 `../art/expression-staging.md`。
- 14 张 ComfyUI CG：六结局各一张，另有梦船、渡河、祭祀、旧名、芈吹笛、雪夜、光河及告别八个剧情瞬间。依实际读到的剧情页解锁，CG 演出不叠加人物立绘。
- 母亲、狗子、周老师、道士、阿蘅五张新增透明立绘。芈登记五处明确在场：三页显示既有立绘、两页采用 CG，另有独立吹笛 CG。
- 依据、真实 PNG 生成元数据与种子、SHA-256、衍生格式和登记状态见 `../art/delivery.md`、`../art/source-manifest.json`、`../art/generation-plan.json`；实际情绪覆盖见 `../art/expression-usage.md`。
- 27 张背景无损原画共 36,772,850 字节。`../art/background-sources.json` 记录 26 个直接 PNG 来源及日间教室的既有调色步骤，`python scripts/verify-originals.py` 验证全部 27 张的像素和哈希；记录见 `../art/original-pixel-verification.json`。

## 验证范围

浏览器检查使用独立的模拟进度，不读取或改写玩家实际存档。每个测试自行启动、关闭生产预览服务；帧时门槛单独执行，避免多个浏览器进程竞争。Windows Playwright WebKit 为兼容性检查，不等同于 iOS 真机 Safari。

最终单文件离线版为 92,874,047 字节（约 88.57 MiB），内嵌 148 张轻量图片、27 张无损原画和 51 个音频资源。2026-11-14 最终串行回归 13/13 组通过；详细临时日志与截图保留在本机 `artifacts/ui-fix-3/`，不纳入发布资源。

| 检查 | 最终结果 |
|---|---|
| TypeScript、生产网站及单文件构建 | 通过 |
| 单元测试（剧情、演出、自动阅读、声音等） | 36/36 通过 |

Chromium 独立帧时检查未放宽门限：旁白后人物恢复 187ms（≤250ms），缓存换人 243ms（≤300ms）。短句在打字完成后约 1854ms 推进；两个选择设置分支的盖章音起点分别为 302ms、306ms，贴合约 300ms 的动画接触点。

Windows WebKit 不提供 Web Audio，本轮仅验证其原生媒体降级路径、自动阅读及选择后的继续行为，不将其作为盖章音起点的测量证据。iOS Safari 的音频手势与真机内存表现仍需设备验证。
